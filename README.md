# 개요
로그인 기능 및 TodoList의 생성/수정/삭제/조회가 가능한 일정관리앱입니다.

# 기술 스택
- **Language:** Java 17
- **Framework:** Spring Boot 4.0.2
- **Data Access:** Spring Data JPA
- **Database:** MySQL
- **Other Tools:** Lombok, Spring Validation, Postman
